# Security Policy

Report vulnerabilities privately to the repository owner through GitHub Security Advisories. Do not publish exploit details before a fix is available.

This package is a read-only AGG adapter. It must never gain a database handle, SQL execution surface, transaction callback, network client, shell/process execution, approval writer, trust-root mutation, or dispatch authority. Security fixes must preserve fail-closed behavior for malformed, duplicate, stale, hash-mismatched, or unbound evidence.
